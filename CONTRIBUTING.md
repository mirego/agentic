# Comment contribuer

## Un mot sur le projet

Tout d'abord, merci de votre intérêt à contribuer à ce projet!

mirego-agentic est une collection de packages [APM](https://github.com/microsoft/apm) partagés qui standardisent les workflows de développement assistés par IA chez Mirego. Il distribue des skills, commandes et prompts vers Claude Code, OpenCode et GitHub Copilot.

Bien que nous acceptions les pull requests et suggestions, ce projet reflète notre façon de travailler chez Mirego. Nous avons décidé de le rendre public pour que d'autres puissent bénéficier de notre expérience en matière de workflows de développement augmentés par l'IA — et peut-être baser leurs propres packages dessus!

## Contribuer

Nous vous suggérons fortement d'ouvrir une issue avant de commencer à travailler sur du code que vous aimeriez voir dans ce projet. Cela vous évitera, par exemple, d'implémenter une fonctionnalité que nous avons déjà discutée et décidé de ne pas inclure.

Les corrections de bogues et de coquilles sont toujours les bienvenues, bien sûr 🙂

Merci! ❤️
